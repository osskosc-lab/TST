# TST

Reproducible falsification experiments for the Transformative Seeking (TST) framework.

The first registered experiment is **TST Phase 1: Dynamic Network Temporal-Order Falsification**. Its purpose is not to encode `Shadow → Seeking → Transformation` into a simulator, but to test whether that ordering appears in a TST-agnostic online learning system.

See `phase1/PREREGISTRATION_v1.0.md` and `phase1/results/confirmatory/REPORT.md`.
